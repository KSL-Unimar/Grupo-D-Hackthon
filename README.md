# Grupo D - Build With AI HACKATHON ( 2026 )
## Projeto de ChatBot
Neste projeto criamos um prótotipo de um chatbot capaz de agendar serviços estéticos automotivos.
Sendo possível posteriormente implementá-lo junto à um aplicativo mobile. Além de enviar o output para o funcionário responsável pelos agendamentos, automatizando o processo de agendamento da empresa.
